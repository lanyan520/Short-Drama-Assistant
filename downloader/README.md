# 无水印下载器

本地 Web 应用，干一件事：**粘贴抖音 / 小红书链接 → 解析出无水印直链 → 自己选目录 + 分类批量下载**。

没有左侧导航、没有关键词搜索、没有演示数据。就一个文本框 + 解析 + 下载。

## 启动

```bash
./start.sh
```

首次运行自动建虚拟环境装依赖（`fastapi` / `uvicorn` / `httpx` / `gmssl` / `Pillow`），随后浏览器自动打开 <http://127.0.0.1:8899>。
服务常驻后台；改完代码用 `lsof -ti tcp:8899 | xargs kill -9` 后可重跑 `start.sh`。

## 用法

1. 把抖音 / 小红书分享链接粘进文本框（每行一个，可一次多个）。
2. 点「解析」——**自动识别平台与每条内容的类型**（视频 / 图片一并返回，无需手动切换）。
3. 结果按作者卡片展示，每位作者下再**分「视频」「图片」两块**列出作品，每块可单独「全选本类」。
   每个素材下方直接显示**无水印直链**，可一键复制。
4. 点素材选中、或点「全选一类 / 全选全部」；底部 dock 显示已选数量。
5. 点「下载到本地」：先弹 **macOS 原生目录选择框**选保存位置，再按下拉框选**分类**，文件落到
   `你选的目录 / 分类 / 平台 / 类型 / 作者 / 文件名`。

## 平台能力（实测）

| 平台 | 是否要 Cookie | 说明 |
|---|---|---|
| 抖音 | **不要** | `aweme/detail` 单视频/图集详情接口对匿名开放，靠匿名 `ttwid` + 真实 `a_bogus` 签名（来自开源项目 `f2`，MIT）即可拿到无水印直链。 |
| 小红书 | **要** | 笔记接口强制登录（`-101`）。在右上角「设置」里粘贴含 `a1` + `web_session` 的 Cookie 后可解析。未填则提示「需要登录」。 |

> 注：抖音**搜索**接口是强制登录的（返回 `2483`），但**单条链接解析**不需要登录——这就是本工具只做「链接解析」而非「关键词搜索」的原因。

### 个人主页作品列表（实测 2026-08-13）

粘贴抖音 / 小红书的**个人主页链接**即可拉取该用户**全部作品**（一个作者卡片 + 该用户所有作品瀑布流）：

- **抖音**：`douyin.com/user/<sec_user_id>`（也支持重定向到用户页的 `v.douyin.com` 短链）。走 `aweme/post` 接口，**匿名可用**——与搜索不同，不会返回 `2483`，已实测 `status_code:0` 且可正常翻页。自动识别每条作品类型，视频与图片一并拉取（接口用 `publish_video` 0/2 两次拉取并去重）；翻页上限 60 页（约 1200 条）防止失控。
- **小红书**：`xiaohongshu.com/user/profile/<user_id>`。走 `user_posted` 接口，**仍需 Cookie**（与单条笔记一致）；未填则提示登录。

## 已知边界

- 小红书真实内容必须填 Cookie，纯免登录解析不成立。
- 抖音仅支持单条视频 / 图集链接解析（搜索/批量发现不在范围内）。
- `a_bogus` 与 `x-s` 签名会随平台前端更新失效；失效时界面会显示明确错误，届时更新 `adapters/` 下对应签名文件即可。
- 小红书视频需在 Cookie 有效时解析；若接口返回缺 `master_url`，下载会提示「缺少可下载直链」。

## 目录结构

```
douyin-xhs-downloader/
├── server.py              FastAPI：/api/parse /api/proxy /api/pick-dir /api/download(+SSE)
├── config.py              配置持久化（Cookie、并发、分类、最近目录）
├── downloader.py          并发下载引擎（按平台加 Referer 防盗链、断点写 .part）
├── native.py              macOS 原生目录选择 / 访达定位 / 系统通知
├── adapters/
│   ├── base.py            Author / MediaItem 数据模型
│   ├── parse_link.py      链接解析入口（抖音免登录 + 小红书需 Cookie，自动识别平台）
│   ├── abogus.py          抖音 a_bogus 签名（来自开源项目 f2）
│   ├── xbogus.py          X-Bogus 签名
│   └── xhs_sign.py        小红书 x-s / x-t 签名
└── web/                   原生 HTML/CSS/JS 前端（无构建步骤）
```
